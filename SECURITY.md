# Security Policy

## Supported versions

Phi is preparing its first public beta. No public version is supported before that release. During beta, only the
latest published beta release receives security fixes.

| Version | Supported |
| --- | --- |
| Unreleased code | No |
| Latest published beta | Yes |
| Earlier releases | No |

## Report a vulnerability

Email security reports to [info@dicehub.com](mailto:info@dicehub.com). Use the subject `Phi security report`.

Do not open a public issue for a suspected vulnerability. Include this information when possible:

- affected Phi version;
- affected component or package;
- impact;
- steps or code that reproduce the problem;
- suggested fix or mitigation, if known;
- a safe way to contact you.

Do not include live credentials, customer data, or other personal data in the report. We will work with you on a
safe method to exchange additional sensitive information when required.

We will confirm the report and share status updates when possible. Please allow time for a fix before public
disclosure.
